# gurukiran10.github.io

Personal portfolio of **Gurukiran S**, an AI engineer who builds agentic systems that do real work and verify it.

Built by hand in plain HTML, CSS and JavaScript. No framework, no build step, three files.

## Features
- Hero with a looping **agent trace terminal**: plan → act → ask a human → recover → independent verify
- **Command palette** (`Ctrl/⌘ + K`) to jump to sections, copy email or open projects
- Dark and light themes that follow the system setting and remember your choice
- Cursor-follow glow, spotlight hover on cards, scroll reveals, count-up stats
- Responsive down to 360px, respects `prefers-reduced-motion`

## Run locally
```bash
python -m http.server 5173
```

## Deploy (GitHub Pages)
1. Create a repo named `Gurukiran10.github.io`
2. Push `index.html`, `styles.css`, `script.js`
3. The site goes live at https://gurukiran10.github.io

Or import the repo into Vercel with zero config.
