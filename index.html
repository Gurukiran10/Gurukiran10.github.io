02 — How I build

Four rules I
actually follow.

i.

Verify, don't trust.

An agent saying "done" is a claim. I re-check the real system state with a separate verifier, preferably on a different model.

ii.

The LLM writes, code decides.

Models are good with language and bad at counting, limits and rules. Anything deterministic goes in code, where it can be tested.

iii.

Write the evals first.

Held-out tasks are written before the first run. If I can't measure it, I don't put it in the README.

iv.

Humans own the decisions.

Money, people and anything irreversible get a human checkpoint. Good agents ask once, then remember the answer.
